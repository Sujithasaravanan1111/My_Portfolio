Project 01 · Productivity App

Daily Routine Tracker

A full-stack productivity web app with glassmorphism UI — combining routine tracking, workout management, streaks, reminders, notes, analytics, and motivational quotes all in one elegant dashboard.

🎯 Challenge
Scattered productivity tools force users to juggle multiple apps. The challenge was creating one unified dashboard that handles diverse routines without becoming cluttered or overwhelming.
⚡ Solution
Built a modular Next.js app with Prisma ORM + SQLite for persistent data, custom CSS animations for the glassmorphism UI, and Next.js API Routes for a seamless full-stack experience — deployed on Vercel.
📈 Result
Live production deployment at daily-routine-tracker.vercel.app with a scalable architecture ready for PostgreSQL migration and multi-user support.

Project 02 · AI Application

NeuroPath AI — Personalized Learning Platform

An AI-powered adaptive learning platform that generates custom learning paths, interactive quizzes, and real-time AI tutor chat — making education personal, engaging, and intelligent.

🎯 Challenge
Traditional learning platforms offer static, one-size-fits-all content. Learners disengage when content doesn't adapt to their pace, style, or knowledge gaps.
⚡ Solution
Integrated OpenRouter AI API for dynamic content generation, Firebase for authentication and real-time data, Framer Motion for smooth UX, and a scalable React + Vite architecture for performance.
📈 Result
Fully functional AI learning platform with progress tracking, quiz generation, and interactive tutoring — ready for real-world deployment and future expansion.
